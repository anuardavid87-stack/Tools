Herramientas de Sincronización Manual

Si acabas de configurar Supabase por primera vez, puedes subir todos los datos que tienes guardados localmente a la nube con un solo clic.

¿Cómo obtener las credenciales de Supabase?
  1. Crea una cuenta y un proyecto gratis en supabase.com.
  2. Abre el menú SQL Editor, abre el archivo supabase_schema.sql de tu proyecto, copia su contenido, pégalo en una nueva consulta y haz clic en Run.
  3. Ve a Project Settings > Data API (o API), copia la Project URL y la anon public key, y pégalas en este formulario.

💡 Tip: También puedes pegar las credenciales en el archivo supabase-config.js antes de desplegar en Vercel para que carguen automáticamente para todos los usuarios.
